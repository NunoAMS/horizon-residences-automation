# 🏢 Horizon Residences - Sistema Inteligente de Automação de Leads

Uma solução completa de **Front-End Premium** e **Automação Serverless** desenhada especificamente para maximizar a conversão e otimizar a gestão de contactos no setor imobiliário de luxo. 

Este projeto demonstra como pequenas e médias empresas (PMEs) podem capturar, estruturar e responder a potenciais clientes instantaneamente sem qualquer custo recorrente com infraestrutura de servidores, bases de dados ou CRMs caros.

🔗 **[Aceder ao Projeto Online (Live Demo)](COLA_AQUI_O_TEU_LINK_DO_GITHUB_PAGES)**

---

## 🚀 Funcionalidades de Negócio

* **Design de Alto Padrão (Front-End):** Interface limpa, moderna e totalmente responsiva adaptada para o público do mercado imobiliário premium, utilizando Tailwind CSS.
* **Integração Síncrona via API (Serverless):** O formulário comunica diretamente com um endpoint customizado rodando em Google Apps Script, eliminando a necessidade de servidores dedicados (Node.js, Python, etc.).
* **Gestão de Dados Centralizada:** Armazenamento estruturado e automático de dados (incluindo qualificação de lead por prazo de compra) em tempo real numa Google Sheet.
* **Automação de E-mail Marketing Instantânea:** Envio imediato de uma confirmação personalizada com um template HTML profissional através do serviço nativo do Gmail para a caixa de entrada do utilizador.

---

## 🛠️ Arquitetura e Tecnologias

* **Camada Visual:** HTML5, Tailwind CSS (estilização avançada e grids responsivos).
* **Camada de Comunicação:** JavaScript Assíncrono (Fetch API com tratamento de payloads JSON).
* **Mecanismo de Back-End:** Google Apps Script (Engine Serverless baseada em JavaScript V8).
* **Persistência de Dados & Serviços:** Google Sheets API & Gmail Application Service.

---

## ⚙️ Como Testar a Solução

1. Abra o link do **[Live Demo](COLA_AQUI_O_TEU_LINK_DO_GITHUB_PAGES)**.
2. Preencha os dados do formulário fictício (insira um e-mail real seu para verificar o disparo do e-mail).
3. Submeta o formulário e verifique a resposta visual instantânea.
4. O sistema registrará os dados síncronos na base de dados interna e disparará o e-mail em formato corporativo HTML.
